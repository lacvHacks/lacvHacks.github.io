# LACV — Sitio de Luis Caicedo

Sitio personal de **Luis Caicedo (LACV)**: contenido sobre Ciberseguridad
(Hacking, Cracking, Criptografía, Esteganografía).

Reconstruido desde cero (solo quedaba el bundle minificado del build
original) como un proyecto fuente **Vite + React 18 + GSAP + SplitType**,
con i18n en español, inglés y portugués (español por defecto), dark mode y
despliegue a GitHub Pages (rama `gh-pages`).

## Desarrollo

```bash
npm install
npm run dev      # servidor de desarrollo
npm run build    # producción (salida en /dist)
npm run deploy   # compila y publica /dist en la rama gh-pages
```

Ver `AGENTS.md` y `IA/CONTEXT.md` para contexto técnico detallado (mapa del
bundle original, recetas de animación y reglas del proyecto).
